### A1 — Comparação de Complexidade Algorítmica

Implementação e comparação empírica de algoritmos com diferentes ordens de crescimento.

Conteúdos previstos:

- algoritmo linear — `O(n)`;
- algoritmo quadrático — `O(n²)`;
- fatorial recursivo — `O(n)`;
- medição de tempo com `time.h`;
- comparação entre resultados empíricos e análise assintótica;
- relatório da atividade prática.
